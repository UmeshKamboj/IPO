📘 Analysis API Documentation
Base URL: /api/analysis
1️⃣ POST /api/analysis/calculate — Preview (no save)
2️⃣ POST /api/analysis/submit — Calculate + Save to DB
Both endpoints use the same request payload, the difference is submit persists to DB.

3️⃣ GET /api/analysis/{ipoId} — Get all saved analyses
Example: GET /api/analysis/2046

Response:

{
  "success": true,
  "data": [
    { "analysisType": 1, "ipoPricePerShare": 59.0, "subscriptions": { ... }, ... },
    { "analysisType": 2, ... },
    { "analysisType": 3, ... }
  ]
}

4️⃣ GET /api/analysis/{ipoId}/{type} — Get specific tab
Example: GET /api/analysis/2046/2 (After Allotment)

Response: Same structure as single response above.

📋 Frontend Mapping to UI Tables
UI Section	Response Field
Subscription table (AppForOneTime, AvgShare, IPOSubscription)	subscriptions.Retail, .SHNI, .BHNI
Kostak/Subject Rate table (Without/With Profit Margin)	kostakRates, subjectToRates
Order Count table (BUY/SELL/NET for Kostak/SubjectTo/Premium)	kostakCount, subjectToCount, premiumCount
Share Qty table (Purchase/Sell/NET)	kostakShareQty, subjectToShareQty, premiumShareQty
Difference Qty (To Hedge)	differenceQtyToHedge
Profit Or Loss (Tab 3 only)	profitOrLoss
IPO Price Per Share	ipoPricePerShare
